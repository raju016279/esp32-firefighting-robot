# 🔥 ESP32 Firefighting Robot

An ESP32-based autonomous firefighting robot designed for fire detection,
obstacle avoidance, and real-time monitoring.

## 🚀 Features

- 🔥 Fire detection
- 🤖 Autonomous robot movement
- 🚧 Obstacle avoidance
- 🌐 IoT-based monitoring
- 💧 Fire suppression

## 🛠️ Technologies Used

- ESP32
- C/C++
- Arduino IDE
- Wi-Fi
- IoT
- Sensors
- Motor Control

## 🔧 Hardware Components

- ESP32
- Fire/Flame Sensor
- Ultrasonic Sensor
- Motor Driver
- DC Motors
- Robot Chassis
- Fire Suppression System

## ⚙️ Working Principle

1. The fire sensor detects a fire source.
2. The ESP32 processes the sensor information.
3. The robot moves toward the target while avoiding obstacles.
4. When the fire is detected, the suppression mechanism is activated.
5. IoT communication can be used for real-time monitoring.
